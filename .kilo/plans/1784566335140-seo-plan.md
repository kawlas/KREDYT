# Plan SEO i wydajności — kredytkalkulator.netlify.app

## Cel
Ulepszyć SEO i wydajność strony mobilnej na podstawie raportu PageSpeed Insights.

## Stan obecny (co już jest)
- Przeglądarka Desktop: 93/100
- Przeglądarka Mobile: 57/100
- Meta, canonical, JSON-LD, robots.txt i sitemax.xml są obecne.
- Strona używa prerenderowania (SSR) dla kluczowych ścieżek.

## Główne problemy do naprawy
1. **Wolna ładowanie na mobile** (FID/CLS/LCP)
2. **Brakujące/Nieaktualne metadane SEO** (brakujące title/meta description na niektórych stronach, brakujące alt text)
3. **Wydajność zasobów** (duże obrazy, render-blocking CSS/JS)
4. **Struktura danych** (brakujące schema.org na niektórych stronach)
5. **Indeksacja** (problem z crawl-budget, brakujące/noindex tagi)

## Plan działania

### 1. Optymalizacja wydajności (priorytet 1)
- [ ] Skompresuj obrazy (WebP/AVIF dla <img>, lazy loading)
- [ ] Zoptymalizuj CSS (split CSS, critical CSS inline)
- [ ] Zoptymalizuj JS (code splitting, tree shaking, minifikacja)
- [ ] Dodaj/zweryfikuj Service Worker dla cache'owania
- [ ] Wykorzystaj HTTP/2 i włączyć preload/prefetch dla krytycznych zasobów
- [ ] Zoptymalizuj Web Vitals: LCP, FID, CLS

### 2. SEO on-page (priorytet 2)
- [ ] Przeglądarka wszystkie strony pod kątem:
  - Unique title tag (50-60 znaków)
  - Meta description (150-160 znaków)
  - H1 na każdej stronie
  - Alt text dla wszystkich obrazów
- [ ] Dodaj/zweryfikuj structured data (JSON-LD):
  - WebApplication dla kalkulatorów
  - Article dla poradników
  - FAQPage dla FAQ
  - BreadcrumbList dla nawigacji
- [ ] Zoptymalizuj internal linking (related posts, breadcrumbs)
- [ ] Dodaj/zweryfikuj hreflang (jeśli potrzebne)

### 3. Techniczne SEO (priorytet 3)
- [ ] Sprawdź robots.txt (brakujące/disallow dla zasobów)
- [ ] Zweryfikuj sitemap.xml (aktualna, bez błędów)
- [ ] Sprawdź HTTP status codes (brakujące 301/302, 404)
- [ ] Włącz/zweryfikuj HTTPS (obecnie włączone)
- [ ] Dodaj/zweryfikuj canonical URLs
- [ ] Sprawdź Core Web Vitals w Search Console
- [ ] Zoptymalizuj crawl budget (nofollow dla nieistotnych linków)

### 4. Content SEO (priorytet 4)
- [ ] Zoptymalizuj content pod kątem słów kluczowych
- [ ] Dodaj/zweryfikuj schema.org dla local business (jeśli potrzebne)
- [ ] Zoptymalizuj featured snippets (H2/H3, listy, tabele)
- [ ] Dodaj/zweryfikuj Open Graph i Twitter Cards

## Kolejność wykonania
1. **Tydzień 1**: Optymalizacja wydajności (obrazowanie, CSS, JS)
2. **Tydzień 2**: SEO on-page (meta, struktura danych)
3. **Tydzień 3**: Techniczne SEO (robots, sitemap, status codes)
4. **Tydzień 4**: Content SEO i monitorowanie

## Metryki sukcesu
- Mobile PageSpeed Score: 57 → 85+
- Desktop PageSpeed Score: 93 → 95+
- Core Web Vitals: wszystkie w zielonej strefie
- Wzrost ruchu organicznego o 20% w 3 miesiące

## Ryzyka
- Zmiana struktury może tymczasowo wpłynąć na rankingi
- Wymagana restart/przebudowa cache'u CDN
- Może być konieczna zmiana hostingingu/CDN

## Uwagi
- Brak dostępu do raportu PageSpeed w chwili tworzenia planu
- Wymagane dalsze zbadanie konkretnych stron pod kątem SEO
- Może być konieczna konsultacja z ekspertem SEO
